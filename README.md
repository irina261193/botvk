# Бот рассылок ВКонтакте

Локальный бот сообщества ВК. Пользователь сам подписывается командой `Подписаться` и может в любой момент написать `Отписаться`. Список подписчиков хранится локально в `data/subscribers.json`.

## 1. Настройка сообщества ВК

1. Откройте **Управление → Сообщения** и включите сообщения сообщества.
2. Откройте **Управление → Работа с API → Ключи доступа**.
3. Создайте ключ с правом **Сообщения сообщества**. Никому его не показывайте.
4. В разделе **Long Poll API** включите Long Poll и выберите актуальную версию API.
5. На вкладке типов событий включите **Входящие сообщения** и **Запрет сообщений от сообщества**.
6. Там же включите событие **Вступление в сообщество**.

## 2. Настройка проекта

Скопируйте `.env.example` в `.env`:

```powershell
Copy-Item .env.example .env
```

Откройте `.env` и заполните:

- `VK_TOKEN` — ключ доступа сообщества;
- `VK_GROUP_ID` — числовой ID сообщества без `-`;
- `ADMIN_IDS` — ваш числовой VK ID. Несколько ID можно указать через запятую.

## 3. Запуск

Нужен Node.js 20 или новее. Зависимости устанавливать не требуется.

```powershell
node src/index.js
```

Если в журнале появляется ошибка `[15] Access denied`, откройте **Управление сообществом → Работа с API → Long Poll API**, включите Long Poll и сохраните настройки. В типах событий должны быть включены входящие сообщения, запрет сообщений и вступление в сообщество.

Остановка: `Ctrl+C`.

При первом разрешённом сообщении бот загружает `output/pdf/welcome.pdf` в документы ВК и затем переиспользует вложение. Новый участник получит его сразу после вступления, если он уже разрешил сообщения сообщества. Если сообщения ещё не разрешены, файл будет отправлен после команды `Подписаться`.

## Команды в сообщениях сообщества

Для пользователя:

- `Подписаться`
- `Отписаться`
- `Помощь`

Для администратора:

- `Статистика`
- `Рассылка Текст сообщения`

Текст рассылки можно написать с новой строки:

```text
Рассылка
Завтра в 19:00 состоится прямой эфир!
```

Перед настоящей рассылкой рекомендуется проверить сообщение на небольшой тестовой группе.
